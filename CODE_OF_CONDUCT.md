# Code of Conduct

## Our Standard

CryptHub is a small open source project. Contributions and interactions should be respectful, focused, and constructive.

Expected behaviour:
- Be respectful in all communications
- Give and accept constructive feedback professionally
- Focus on what is best for the project and its users
- Accept that maintainers make final decisions on project direction

Unacceptable behaviour:
- Harassment, personal attacks, or discriminatory language
- Spam or off-topic promotion
- Deliberate intimidation or trolling

---

## Scope

This applies to all project spaces — GitHub issues, pull requests, discussions, and any other communication related to CryptHub.

---

## Enforcement

Violations may result in comments being removed or contributors being blocked from the repository.  
To report an issue, contact the maintainer via GitHub.
